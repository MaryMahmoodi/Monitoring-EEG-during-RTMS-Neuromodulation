# Monitoring-EEG-during-RTMS-Neuromodulation
High frequency (transcranial magnetic stimulation) RTMS like 10 Hz repetitive pulses induces neuroplasticity changes, the ability of the brain to reorganize itself.
Neuroplastic changes could be measured by excitability/connectivity metrics.
Monitoring EEG excitability/connectivity chnages during RTMS is the key to personalized neuromodulation.
